# บทที่ 8 — รายงาน

TEAS มีรายงาน 14 หน้าใต้เมนู "รายงาน" ครอบคลุมตั้งแต่งบการเงินหลักไปจนถึงรายงาน
บริหารเฉพาะทาง (อายุหนี้, กระทบยอดธนาคาร, ภาษีหัก ณ ที่จ่ายค้างรับ) ทุกตัวเลข
**ลงจากบัญชีแยกประเภท (GL) ที่ระบบบันทึกให้อัตโนมัติทุกครั้งที่บันทึกบัญชีเอกสาร**
— ไม่ต้องคีย์ซ้ำ และตัวเลขจะ**ตรงกันข้ามรายงาน** (หลายหน้ามี badge "Dr = Cr"
ยืนยันความสมดุล).

ก่อนเริ่มอ่านบทนี้ คุณควรมี:

- สิทธิ์อ่านรายงานที่ต้องการดู — เมนูรายงานแต่ละหัวข้อ gate ด้วย permission เฉพาะทาง
  (เช่น `report.trial_balance.read`, `report.general_ledger.read`, `bank.report.read`,
  `sales.tax_invoice.read`, `purchase.purchase_order.read`, `tax.pnd30.read`,
  `tax.pnd53.read`) — เห็นเมนูไม่ครบทุกหัวข้อ = role ยังไม่ได้รับสิทธิ์บางตัว
  ไม่ใช่ระบบผิดพลาด
- มีเอกสาร**ที่บันทึกบัญชีแล้ว (Post)** อย่างน้อยบางส่วน (บทที่ 4–7) — ทุกรายงาน
  อ่านจากเอกสารที่ Post แล้วเท่านั้น เอกสารสถานะร่างจะไม่ถูกนับรวม

## แนวคิดที่ควรรู้ก่อนเริ่ม

### งบทดลอง (Trial Balance)

แสดงยอดทุกบัญชี ณ วันที่เลือก (default วันนี้) — คอลัมน์เดบิต/เครดิต/สุทธิต่อบัญชี,
toggle **"รวมบัญชีที่ปิดใช้งานแล้ว"** เพื่อดูบัญชีที่ deactivate ไปแล้วด้วย, badge
**"สมดุล ✓ (Dr = Cr)"** มุมบนยืนยันว่ายอดเดบิตรวม = เครดิตรวม และปุ่ม **"ส่งออก CSV"**.

### งบแสดงฐานะการเงิน (Balance Sheet)

แบ่งเป็น 3 ส่วน **สินทรัพย์ / หนี้สิน / ส่วนของผู้ถือหุ้น** ณ วันที่เลือก พร้อมแถว
**"กำไรสะสมงวดปัจจุบัน"** (กำไรที่ยังไม่ถูกปิดบัญชีเข้าส่วนของผู้ถือหุ้นถาวร) และยอดรวม
หนี้สิน + ทุน — มี badge สมดุลเช่นเดียวกับงบทดลอง ปุ่มส่งออกมีทั้ง **CSV** และ
**"PDF งบการเงินทั้งปี"** (รวมงบกำไรขาดทุนของปีนั้นไว้ในไฟล์เดียวกัน).

### กำไรขาดทุน ตามหน่วยธุรกิจ (Profit & Loss)

ช่วงวันที่ default เป็น**เดือนปัจจุบัน** พร้อมปุ่ม preset "เดือนนี้" / "ปีนี้", เลือกดู
หน่วยธุรกิจ (BU) เดียวหรือ "ทุกหน่วยธุรกิจ" เพื่อเทียบผลแต่ละหน่วยเป็นแถว, toggle
**"รวมรายการไม่ระบุหน่วยธุรกิจ"** สำหรับเอกสารเก่าที่ไม่ได้ผูก BU ปุ่มส่งออกมีทั้ง
**CSV** และ **"PDF งบการเงินทั้งปี"** เช่นเดียวกับงบแสดงฐานะการเงิน.

### บัญชีแยกประเภทรายบัญชี (General Ledger)

เลือกบัญชีได้ 2 ทาง — **พิมพ์รหัสบัญชีตรง ๆ** (เช่น `1120`) หรือ **เลือกจากรายการ**
(แสดง "รหัส — ชื่อบัญชี") ระบบ resolve ให้เอง, ช่วงวันที่ default เดือนปัจจุบัน, กด
**"แสดงรายงาน"** เพื่อดึงข้อมูล ตารางแสดง **ยอดยกมา** (opening balance) → รายการ
เคลื่อนไหวแต่ละวัน (คลิกเลขที่เอกสารเปิดสมุดรายวันต้นทางได้โดยตรง) → **ยอดยกไป**
(closing balance) วันที่ในตารางแสดงเป็น พ.ศ. ดาวน์โหลดได้ทั้ง **PDF** และ **CSV**.

### สรุปภาษีและผลประกอบการรายเดือน (Tax Summary)

แดชบอร์ดภาพรวม**ทั้งปี** — เลือกปี + หน่วยธุรกิจ (ถ้าต้องการ) แล้วดู การ์ด KPI
(รายได้ / รายจ่าย / กำไรสุทธิ / VAT สุทธิ / ภาษีหัก ณ ที่จ่ายที่นำส่ง / ภาษีที่ถูกหัก
รอเครดิต), กราฟรายเดือน, และตาราง 12 เดือนที่แตกตัวเลขทุกประเภทละเอียด (VAT ขาย/ซื้อ,
ภ.ง.ด.1/3/53/54) พร้อมลิงก์เจาะลึกไปหน้าแบบยื่นจริง **นับเฉพาะเอกสารที่บันทึกบัญชี
(Post) แล้ว** เอกสารร่างจะไม่รวมอยู่ในตัวเลขใด ๆ.

### กระทบยอดธนาคาร (Bank Reconciliation)

ต้องมี**บัญชีธนาคาร**อย่างน้อย 1 บัญชีในระบบก่อน — ถ้ายังไม่มี ระบบจะแสดงข้อความ
พร้อมลิงก์ไปหน้าเพิ่มบัญชีธนาคารให้ทันที เมื่อเลือกบัญชี + ช่วงวันที่แล้ว จะเห็นสรุป
ยอดตามสเตทเมนต์ / ยอดตาม GL / รายการฝากระหว่างทาง / รายการจ่ายที่ยังไม่เคลียร์ /
รายการที่ยังไม่จับคู่ พร้อมผลต่าง (ไฮไลต์สีแดงถ้าไม่เท่ากับ 0) และปุ่ม **"ส่งออก CSV"**.

### อายุหนี้ลูกหนี้ / เจ้าหนี้ (AR / AP Aging)

สรุปยอดค้างชำระแยกตาม**ช่วงอายุหนี้**: ยังไม่ครบกำหนด (current) · 31–60 วัน ·
61–90 วัน · เกิน 90 วัน นับจากกำหนดชำระถึงวันที่เลือก (default วันนี้) มี**การ์ด
กระทบยอดกับบัญชีคุมยอด (control account tie-out)** ยืนยันว่ายอดรวมลูกหนี้/เจ้าหนี้
ย่อยตรงกับบัญชีแยกประเภทควบคุม — badge "สมดุล" หรือ "ไม่ตรง" กรองดูลูกหนี้/เจ้าหนี้
รายเดียวได้ และมีปุ่ม **"ส่งออก CSV"**.

### ลูกหนี้ / เจ้าหนี้รายตัว (Customer Statement / Vendor Ledger)

เลือกคู่ค้าผ่าน**ช่องค้นหา (picker)** แทนการพิมพ์รหัสตรง ๆ + เลือกช่วงวันที่ (default
เดือนปัจจุบัน) แล้วกด **"แสดงรายงาน"** จะเห็น **ยอดยกมา** → รายการเอกสารแต่ละใบ
(ประเภทเอกสาร, เลขที่, เดบิต/เครดิต, ยอดคงเหลือสะสม) → **ยอดยกไป** พร้อมการ์ด
กระทบยอดกับบัญชีคุมยอดเช่นเดียวกับหน้าอายุหนี้ วันที่ในตารางแสดงเป็น พ.ศ.

### สรุปยอดขาย (Sales Summary)

เลือกช่วงวันที่ (default เดือนนี้ พร้อมปุ่ม preset เดือนนี้/ปีนี้) และจัดกลุ่มตาม
**ลูกค้า / หน่วยธุรกิจ / สินค้า** — แสดงจำนวนเอกสาร, ยอดก่อน VAT, VAT, ยอดรวมต่อกลุ่ม.

> ⚠️ **ข้อควรระวัง — รายงานนี้อิงเฉพาะใบกำกับภาษีขายที่บันทึกบัญชี (Post) แล้ว**
>
> บริษัทที่**ไม่ได้จดทะเบียน VAT** และขายผ่าน**ใบเสร็จ**เพียงอย่างเดียว (ไม่ออกใบกำกับ
> ภาษี) จะเห็นหน้านี้**ว่างเปล่าเสมอ** — ไม่ใช่ข้อมูลหายหรือระบบผิดพลาด หน้ารายงานเองก็มี
> footnote อธิบายไว้เช่นกัน หากต้องการดูรายได้รวมของบริษัทกลุ่มนี้ ให้ดูที่
> **งบกำไรขาดทุน** แทน เพราะนับรายได้จากเอกสารขายทุกประเภทที่ Post แล้ว
> ไม่จำกัดเฉพาะใบกำกับภาษี.

### ภ.พ.30 (แบบยื่นภาษีมูลค่าเพิ่ม)

เฉพาะบริษัทที่**จดทะเบียน VAT** เท่านั้นที่เห็นรายงานนี้มีข้อมูล บริษัทที่**ไม่ได้จด
VAT** เข้าหน้านี้จะเห็นข้อความแจ้งว่าไม่ต้องยื่นแบบนี้ (ตาม ม.86 ประมวลรัษฎากร)
รายละเอียดขั้นตอนคำนวณ / preview / finalize / นำส่งแบบเต็มอยู่ในบทที่ 7
ภาษีและการยื่น (🚧 ถัดไป) — หน้านี้ในเมนูรายงานเป็นทางลัดเข้าแบบเดียวกัน.

### PO ค้างส่ง (Outstanding PO)

ใบสั่งซื้อที่ยังได้รับของไม่ครบ ณ วันที่เลือก — คอลัมน์**จำนวนวันเกินกำหนด**
(overdue days) พร้อม badge สีตามความรุนแรง (ปกติ / เตือน / เลยกำหนดมาก) และ toggle
**"เฉพาะที่เลยกำหนด"** กรองเฉพาะรายการที่ควรติดตามเร่งด่วน.

### ภาษีหัก ณ ที่จ่ายค้างรับ (WHT Receivable)

สองส่วนในหน้าเดียว: **ทะเบียน** — รายการที่ถูกลูกค้าหัก ณ ที่จ่ายไว้ (ฝั่งเครดิตของ
บริษัท ใช้อ้างอิงตอนยื่นภาษีเงินได้) ในช่วงวันที่เลือก พร้อมเลขที่หนังสือรับรองหัก
ณ ที่จ่ายถ้ามี, และ **อายุค้างรับ** — จัดกลุ่มตามจำนวนวันค้างรับต่อลูกค้า/เอกสาร
ทั้งสองตารางมีแถวรวมยอดท้ายตาราง.

## จุดขายของบทนี้ — ตัวเลขตรงกันทุกรายงานเพราะลงจาก GL เดียวกัน

ไม่ว่าจะดูรายงานไหน (งบทดลอง, งบแสดงฐานะการเงิน, งบกำไรขาดทุน, บัญชีแยกประเภท ฯลฯ)
ตัวเลขทั้งหมด**ลงจากบัญชีแยกประเภท (GL) เดียวกัน** ที่เกิดจากการบันทึกบัญชีเอกสารใน
บทที่ 4–7 โดยอัตโนมัติ — badge "Dr = Cr" ที่ปรากฏในหลายหน้าคือการยืนยันว่าตัวเลข
สมดุลข้ามรายงาน ไม่ใช่แค่ในหน้าเดียว ถ้าเจอ badge "ไม่สมดุล" หรือ "ไม่ตรง" ให้ตรวจสอบ
เอกสารที่เพิ่งบันทึกบัญชีล่าสุดก่อนเป็นอันดับแรก.

## สิทธิ์การเข้าถึงเมนูรายงาน

แต่ละหัวข้อในเมนูรายงาน gate ด้วย permission แยกกัน (`report.*.read`, `bank.report.read`,
`sales.tax_invoice.read`, `purchase.*.read`, `tax.pnd30.read`, `tax.pnd53.read` ฯลฯ)
— ถ้า user คนใดเห็นเมนูรายงานไม่ครบทุกหัวข้อ ให้ตรวจสอบสิทธิ์ของ role ที่มอบหมายไว้
(ตั้งค่า → บทบาท) ไม่ใช่อาการของระบบผิดพลาด ดูสรุปสิทธิ์ทั้งหมดเพิ่มเติมได้ใน
*คู่มือสิทธิ์การมองเห็น (RBAC UI Guide)*.

## ถ้าเจอหน้า "เกิดข้อผิดพลาด"

บางครั้งหลัง deploy เวอร์ชันใหม่ browser อาจโหลดไฟล์หน้าเว็บเก่าค้างอยู่ ทำให้เจอหน้า
**"เกิดข้อผิดพลาด"** พร้อมปุ่ม **"โหลดใหม่"** — ระบบมีกลไก retry โหลดไฟล์ให้อัตโนมัติ
1 ครั้งอยู่แล้วเมื่อเจอปัญหานี้ ถ้ายังเจอซ้ำหลังกด "โหลดใหม่" ให้ปิดแท็บแล้วเปิดหน้าใหม่
(หรือ hard refresh) ก่อนแจ้งผู้ดูแลระบบ.
